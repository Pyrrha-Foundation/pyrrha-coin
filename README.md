# Pyrrha — A Human-First Proof-of-Work Blockchain

**Pyrrha** is a next-generation Proof-of-Work blockchain designed to restore mining fairness for everyday people — not industrial ASIC farms.

Derived from a mature UTXO-based codebase, Pyrrha evolves significantly in identity, emission, PoW algorithm, consensus tuning, and a devnet-first approach for experimentation.

**Post-ASIC. Post-Farm. Proof-of-Work reborn for real people.**

---

## 🔥 Vision & Mythology

Pyrrha comes from Greek mythology: after the great flood, *Pyrrha* and *Deucalion* repopulated the world by throwing stones behind them — each stone becoming a human.

### Symbolism for the blockchain
- ASIC farms = the “flood” that drowned fair PoW  
- Home miners = the “stones” that repopulate a decentralized network  
- Pyrrha = PoW rebuilt for real people  

**Pyrrha gives Proof-of-Work back to humans.**

---

## 🪙 What is Pyrrha?

Pyrrha is a decentralized UTXO-based blockchain focused on:

- **Real decentralization** via CPU/GPU mining  
- **ASIC-resistant PoW** to prevent industrial dominance  
- **Dynamic, long-term sustainable emission**  
- **UTXO financial primitives** instead of monolithic smart-contract VMs  
- **A research-friendly devnet architecture**  

Pyrrha prioritizes **security, decentralization, and miner accessibility** over ultra-complex L1 programmability.

## 🏛️ Tokenomics (Initial Draft)

### Proof-of-Work Algorithm
- ASIC-resistant  
- CPU + GPU friendly  
- Memory-hard design  
- Potential future hybrid PoW variant  

### Emission Model
- **Fair launch — 0 premine**  
- **0% dev tax**  
- High initial block reward for early adoption  
- Gradual reduction every fixed period  
- **Tail emission** to maintain long-term miner incentives  

### Block Parameters
- **Block Time:** ~1 minute (target)  
- **Model:** UTXO  
- **Supply:** Uncapped with controlled inflation  
- **Dynamic block size:** Automatically adjusts with network usage

## 🛠️ Development Phases

### 📍 **Phase 1 — Rebrand & Chain Constants (CURRENT)**
- Rename all identifiers → "Pyrrha"  
- Update network ports & magic bytes  
- Define new chain parameters  
- Implement ticker: **PYRR**  
- Cleanse seeds & checkpoints  
- Create initial emission schedule  
- Prepare new genesis block infrastructure  
- Update build system & documentation  

---

### 📍 **Phase 2 — Genesis & Devnet Launch**
- Compute new mainnet + testnet genesis blocks  
- Enable Pyrrha private **devnet / regtest**  
- Launch local 1–3 node network  
- Validate mining, emission curve & mempool logic  
- Release Pyrrha Core binaries  
- Deploy explorer + faucet for devnet  

---

### 📍 **Phase 3 — PoW Algorithm Upgrade**
- Integrate fully ASIC-resistant PoW  
- Optimize for CPU/GPU parity  
- Release official Pyrrha Miner  
- Provide pool/solo mining documentation  

---

### 📍 **Phase 4 — Core Protocol Enhancements**
- UTXO-native token model  
- Simple, safe on-chain scripting  
- Improved unconfirmed-chain logic  
- Wallet-level privacy enhancements  
- Memory & performance optimizations  

---

### 📍 **Phase 5 — Ecosystem Expansion**
- Public testnet + mining pools  
- Explorer v2  
- Wallet integrations (desktop + light wallets)  
- Optional cross-chain experimentation  
- Grants for early ecosystem developers  

---

### 📍 **Phase 6 — Mainnet Hardening**
- Final emission tuning  
- Governance discussions  
- Community seed nodes  
- Pre-mainnet security audits  
- Final release candidates
