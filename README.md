# **Pyrrha — A Human-First Proof-of-Work Blockchain**
_Post-ASIC. Post-Farm. Proof-of-Work reborn for real people._

---

## 🌋 Mythology & Vision

**Pyrrha** comes from Greek mythology:  
After the great flood, *Pyrrha* and *Deucalion* repopulate the world by throwing stones behind them — each stone becoming a new human.

### **Narrative Fit for the Blockchain**

- ASIC farms = the “flood” that drowned Proof-of-Work.  
- Home miners = the “stones” that repopulate a fair network.  
- Pyrrha = the rebirth of decentralized mining for everyday people.

**Pyrrha gives Proof-of-Work back to humans.**

---

## 🪙 What is Pyrrha?

Pyrrha is a next-generation Proof-of-Work blockchain designed around a single mission:

> **Make mining fair again — no ASICs, no farms, no industrial dominance.**

Based on a modernized UTXO architecture originally derived from the Pyrrha codebase, Pyrrha delivers:

- ⚡ **Fast layer-1 throughput** with dynamic block sizes  
- 🧱 **Advanced script primitives** for scalable tokens & financial logic  
- 🔗 **Efficient UTXO model** enabling deep unconfirmed chains  
- 🔐 **Decentralized, permissionless, trustless financial operations**

Pyrrha is **not** a smart-contract mega-VM like Ethereum; instead, it offers highly optimized financial primitives directly at the protocol level.

## 🏛️ Tokenomics (Initial Draft)

Pyrrha focuses on long-term sustainability and fair mining:

### 🔹 Proof-of-Work Algorithm  
- ASIC-resistant  
- CPU + GPU friendly  
- Future variants may include custom improvements beyond Autolykos2/RandomX

### 🔹 Emission Model  
- **Fair launch — zero premine**  
- **Zero dev tax**  
- High initial block reward to incentivize early miners  
- Gradual controlled reduction  
- **Small tail emission** for perpetual security  

### 🔹 Block Parameters  
- **Block Time:** ~1 minute (target)  
- **Dynamic Block Size:** Scales with real demand  
- **Supply:** Uncapped, with controlled inflation & tail emission

## 🛣️ Pyrrha Roadmap

### **📍 Phase 1 — Rebrand & Network Identity (CURRENT)**  
- Rename all Pyrrha identifiers → **Pyrrha**  
- Update ports, config names, datadir  
- Assign new network magic bytes  
- Clean seeds & checkpoints  
- Set ticker = **PYRR**  
- Prepare genesis block code  
- Rewrite documentation & branding  

---

### **📍 Phase 2 — Genesis & Network Launch**  
- Compute new genesis (mainnet + testnet)  
- Activate Pyrrha testnet  
- Deploy public seed nodes  
- Release Pyrrha Core binaries (CLI + optional GUI)  
- Add block explorer + faucet for testing  

---

### **📍 Phase 3 — Mining Algorithm Upgrade**  
- Integrate ASIC-resistant PoW:
  - Custom CPU/GPU friendly algorithm  
  - Potential RandomX/autolykos2 hybrid  
- Optimize miner & pool support  
- Release official **Pyrrha Miner**  

---

### **📍 Phase 4 — Core Protocol Enhancements**  
- Advanced token primitives  
- Native NFT support  
- Efficient financial scripting  
- Improve unconfirmed-chain handling  
- Introduce wallet-level privacy features  

---

### **📍 Phase 5 — Ecosystem Expansion**  
- Public mining pools  
- Web-based block explorer v2  
- Wallet integrations (Electrum, hardware wallets)  
- Cross-chain bridges (optional)  
- Ecosystem grants for tool builders  

---

### **📍 Phase 6 — Mainnet Hardening & Long-Term Governance**  
- Long-term emission tuning  
- Community governance phase  
- Strengthen node incentives  
- Decentralized seed infrastructure
